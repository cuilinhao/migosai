# 验证说明

自动化测试源码保留在 `tests/` 和 `components/**/*.test.*`。原始浏览器截图、生产账户与订单记录、供应商响应和生成的测试报告留在被忽略的本地归档，本目录只维护可复现的验证说明。

## 提交和部署前

```sh
npm ci
npm test
npm run typecheck
npm run cf:build
```

构建通过后运行只读页面检查，可将基址替换为独立预览地址：

```sh
node scripts/check-i18n.mjs https://migosai.design
GEO_HTTP_CLIENT=curl python3 scripts/check-geo.py https://migosai.design QA/geo-current.json 50
```

`check-i18n` 检查六种语言的 108 个页面、canonical、语言链接、私有页面 noindex 和 72 个 sitemap URL。`check-geo` 检查公开内容、FAQ 与结构化数据、链接和资源。HTTP 200 不能替代按钮或生成流程验收。
