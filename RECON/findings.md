## 视觉基准

- 背景：`#000000`；主要强调色为紫蓝和青色，橙色主要属于视频内容。来源：`pages/home-styles.json` 和截图。
- 主字体：Plus Jakarta Sans；正文 computed style 为 16px / 24px、400。
- 首页 H1：1440 档为 72px / 72px、700；768/390 档为 36px。来源：`pages/responsive.json`。
- CSS token：`--primary: #818cf8`、`--muted-foreground: #9ca3af`、`--card: #2c2825`、`--border: #3a3633`；具体卡片存在局部覆盖，不能把全局 token 当作所有卡片实测值。
- 首页生成器最大容器宽 1280px；桌面生成器两列、间距 32px；768/390 为单列。`lg:` 样式用于导航和生成器主断点。
- 两个上传槽在桌面及768档并排，在390档上下排列；三个选项在桌面及768档并排，在390档垂直排列。
- Header 桌面显示五项导航、语言按钮和 Sign In；手机显示可展开菜单。
- 首页各区纵向 padding 实测主要为 64/80/96px。完整数值以 JSON 为准。
- 截图中浏览器扩展或系统指针叠加不是产品元素；不纳入复刻实现。

## 视频生成器

- 两个独立上传槽，左/右角色标签，允许 JPG/PNG/WebP，每张最大 10MB。
- 比例选项：9:16（默认）、16:9、4:3、3:4。
- 时长选项：5秒（默认）、10秒、15秒。
- 分辨率选项：720P（默认）、480P；当前原站菜单没有 1080P。
- 未登录时按钮最终为登录后生成；账号检查中是临时加载态。
- 首页预览视频为 `model.mp4`，16:9、object-contain、原生 controls，不自动播放，也不循环。
- 初始积分为0；Buy Credits 跳转 `/pricing`。

## 视频展示

- 首页展示区：4个 **9:16裁切容器**，源文件为横屏；`object-cover`，muted/loop，初始无原生 controls。
- `/showcases`：8个 **16:9横屏容器**，桌面三列；卡片媒体尺寸约387×218px。
- 案例页点击 Play video 后打开标题为 Showcase video 的 Dialog；播放原始横屏视频、显示原生 controls、有声、自动开始、非循环；存在关闭按钮。
- 本地8个素材均为H.264视频+AAC音频，横屏16:9，约5–15秒，总计约64.68MiB。没有旋转元数据。
- 首页独立参考预览是源站第9个视频 `model.mp4`；本地八个案例文件是否包含同一预览尚未逐帧匹配，不能仅凭文件数量宣称素材齐全。
- 后续按画面匹配案例顺序，再生成封面和网页播放优化副本；保留用户原件。

## FAQ 与定价

- 首页9条FAQ默认全部可见，是静态编号问答布局；不是原方案推测的默认折叠 Accordion。
- 歌曲页6条FAQ同样是静态问答。
- 四档积分包价格/积分：9.90美元/300、29.90美元/1200、49.90美元/2200、99.90美元/5000；第二档突出推荐。
- 源站套餐的条数说明与720P生成器显示不一致；正式扣费必须由服务端配置统一，不能照抄卡片说明推导计算。
- HTTP SSR 抓取和浏览器 hydration 后的部分定价文案存在差异，复刻视觉采用渲染后的页面证据。

## 歌曲生成器

- 默认模型 Suno V5；另有 V4.5+、V4.5、V4、V3.5。
- 普通模式：Prompt、Instrumental 开关。
- Custom Mode：Title、Style of Music、Lyrics；Style 显示1000字符上限的计数。
- 自定义模式打开 Instrumental 后，Lyrics 字段隐藏，Title/Style 保留。
- 结果区默认是音频生成空态；每次页面标注10积分。
- 本阶段没有音乐 API 凭据验证，不能把视频 API Key 直接视为歌曲 API Key。

## 登录与语言

- Header Sign In 打开登录弹窗，只有 Google 登录入口；打开弹窗本身没有提交 OAuth。
- `/sign-in`、`/sign-up` 使用独立简洁布局，标题区分登录与注册，均只见 Google 按钮。
- 当前语言菜单仅有 English；没有证据要求实现中文或其他翻译页面。
- 登录后页面/余额/历史记录尚未访问，未来只能基于自己的后端实现与需求补齐。

- 源站日期为2025-10-24；目标站上线日期、域名、运营信息和联系方式须与实际目标站相符。
- 复刻时保留版式与信息层次，条款内容应描述目标站实际服务与数据处理，避免残留原站联系方式。

## 旧方案需覆盖的结论

1. 视觉不是橙色主题；应按黑底、紫蓝渐变、青色强调还原。
2. 独立 Showcase 是横屏三列；首页展示带竖屏裁切，两者不可混用一个固定比例组件。
3. FAQ 不是折叠手风琴。
4. 独立登录/注册路由不能遗漏。
5. 歌曲页是“所有页面”范围内的必做页面，不再作为可省略页面。
6. 固定提示词中的 `Vertical` 需随用户比例变化，不能给16:9请求仍强行写竖屏。
7. 展示项和实际扣费应共享配置；原站套餐数量矛盾需要单独处理。
