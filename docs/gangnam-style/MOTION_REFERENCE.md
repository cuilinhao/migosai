# 自拍接力效果修正

2026-10-28。用户否定第一条真实生成视频；原目标是复刻 `gangnamstyle.io` 的三人自拍样片，旧实现却只输入三张照片和全景骑马舞提示词。测试曾证明接口和文件可用，但没有对照原片镜头，这是验收缺口。

## 原片证据

来源：<https://gangnamstyle.io/assets/photo-trio-seoul-with-audio.mp4>。仓库已有原片，SHA256见素材清单，未换用搜索结果中的19秒或21秒变体。

逐秒抽帧确认：0–2秒三人挤入自拍；约2–4.9秒中间人近景；约4.9–8.4秒开场右侧人近景；约8.4–12.3秒开场左侧人近景；约12.3–15秒回到中间人并三人集合。主要是近距离手持自拍、甩镜、表情和上身手势，其他人会离框。不是固定全身骑马舞。参考片左侧人物自身存在帽子/发型漂移，不能据此改变上传人物身份。

原站公开指南确认上传顺序中/右/左、15秒、480p或720p、生成静音：<https://gangnamstyle.io/guides/gangnam-style-ai-trio-tutorial>。公开前端和指南不包含可核实的后台私有提示词，不能声称已还原该提示词。

## 公开同类做法与修正

- [MakeViral公开模板](https://www.makeviral.ai/templates/gangnam-style-ai-dance)：15秒版本采用照片加参考视频，指定对应人物贯穿各段近景。其上传顺序中/左/右，与本站不同，未直接照抄。
- [AI Trend Clips公开模板](https://aitrendclips.com/gangnam-style-ai/prompt)：分别约束人物身份和参考片运镜；该站21秒版的时间线不用于本站15秒样片。
- [Kie Seedance 2.5官方参数](https://docs.kie.ai/market/bytedance/seedance-2-5)：支持图片与视频联合参考。现原片1280×720、24fps、15秒、约10MB，符合参考视频要求；不混入互斥的首尾帧模式。

新实现由服务端固定 `reference_video_urls` 为 `APP_URL` 的本站样片，客户端不能覆盖；照片仍按中/右/左签名。视频负责镜头、表情、动作和环境，照片负责每个角色的脸、发型和服装。提示词允许独舞阶段其他人离框，并明确不要改成全景舞蹈或新分镜。自拍模式仍只用一张照片，宠物模式将对应动作转换为头部/前爪动作；输出维持静音。

本站收费保持480p 150积分、720p 300积分。按2026-10-28的[供应商报价](https://kie.ai/seedance-2-5)，15秒参考加15秒输出分别约$2.55/$5.70；这是供应商成本，不等于本站积分。参考视频成本应纳入后续定价维护。
