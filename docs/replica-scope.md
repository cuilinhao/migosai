# 应用范围与架构

## 产品范围

应用提供双图视频生成、音乐生成、案例、定价、Google 登录、账户记录、法务和 Hotel Lobby GEO 页面，支持 `en`、`ko`、`ja`、`fr`、`es`、`zh-TW`。具体功能与验证状态见 [README](../README.md)。

视频生成支持 Wan 3.0、Seedance 2.0、Seedance 2.0 Fast 和四种舞台。动作使用内置模板或用户片段；声音使用模板、用户歌曲、片段原声或主题生成。Wan 的参考音频工作流限 Hotel Lobby 舞台；其他舞台使用 Seedance 原创音频。所有组合、时长、清晰度和价格由服务端复核。

## 运行架构

- Next.js 15 / React 19 负责页面和交互，OpenNext 将应用部署到 Cloudflare Workers。
- D1 保存用户、会话、任务、媒体登记、订单和积分账本；R2 保存私有上传、参考素材与结果。
- Google OAuth 提供认证；首次登录发放一次性 50 欢迎积分。
- 新视频提交给 Kie，音乐与历史视频任务保留 APIMart 路径；任务记录供应商，cron 推进异步状态。
- SeeAPI 审核私有视频候选结果，明确通过后才开放读取。
- Waffo Pancake 处理一次性积分包，服务端按签名通知确认订单和积分。

## 必须保留的约束

1. 仅允许用户读取或引用自己的私有媒体；文件扩展名和客户端元数据不能替代服务端验证。
2. 浏览器只上传裁剪转码后的短片段，服务端保存真实时长并据此计价。界面联动不替代后端参数校验。
3. 重复提交、轮询、回调和登录不能重复扣费、退款或发放积分。
4. 上游提交状态不确定时保留人工核对路径；不能在无法确认原任务状态时重新收费生成。
5. 付款回跳不等于成功，成功状态以服务端订单与账本为准。
6. 公开正文与结构化数据可被服务器渲染并保持一致；语言切换、内部链接和登录回跳保留语言。
